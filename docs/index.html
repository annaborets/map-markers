Run it

Requires Node 22.22+, 24.15+ or 26+, and npm.

npm install
npm start                    # http://localhost:4200
npm test -- --watch=false    # run the tests once
npm run build                # production build

Using the app

The map opens on Kyiv with five sample markers.

Add a marker
Click an empty spot on the map. The form opens with the coordinates filled in. Type a name and press Save.
View a marker
Click a marker on the map or in the list. A popup shows its name and coordinates.
Edit a marker
Select it, then change the name or coordinates in the form. Save stays disabled until something has changed.
Move a marker
Drag the selected marker on the map. The new spot is applied when you press Save, and Cancel puts it back.
Delete a marker
Use Delete in the map popup or the trash icon in the list.
Input validation
Name is required. Longitude must be between −180 and 180, and latitude between −90 and 90.

How it works

The map, the list and the form never talk to each other directly. Each one sends requests to a shared store and redraws itself when the store changes.

Key decisions

One source of truth
All data lives in the NGXS store. Components read it with store.selectSignal() and change it only through actions.
Drafts instead of instant writes
Dragging only sets draftPosition. The displayedMarkers selector shows it on top of the saved data, so a drag can be cancelled cleanly.
A map click never creates a marker by itself
It only pre-fills the form. The user always confirms with Save, which prevents accidental markers.
Coordinates stored as lon/lat
The store keeps WGS84 degrees. Conversion to the map projection (EPSG:3857) happens only inside the map component.
Zoneless Angular with signals
Signal changes drive the UI. Forms use Angular signal forms, and the map canvas renders itself.
No component CSS files
Tailwind classes in templates on top of the Angular Material theme. src/styles.css is the only stylesheet.

Known limitations

  • No persistence. Data is in-memory; reloading the page restores the five seed markers.
  • Short click delay. OpenLayers waits about 250 ms after a click to rule out a double-click before it fires.
  • Map component is not unit-tested. The tests cover the state and the form.
